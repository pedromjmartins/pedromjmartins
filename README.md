## Hi there, I'm Pedro Martins 👋

Currently in my final year of Computer Engineering, I’m a Full-Stack Developer driven by practical problem-solving. Whether it's architecting a web application or integrating it with physical hardware, my goal is always to build functional, scalable systems that work in the real world.

### What I've been working on
*Most of my recent work resides in private or organizational repositories. Here is a glimpse of what I've been building:*

*   **Student Accommodation Platform (Production):** Architected and developed an end-to-end platform currently serving the academic community of the University of Évora. I was responsible for the full software lifecycle, from requirements to production deployment.
    *   *Highlights:* Built with React and Java (Spring Boot), PostgreSQL database, Google OAuth2 SSO integration, and SMTP email services.
    *   *DevOps:* Implemented a fully automated CI/CD pipeline using GitHub Actions, Docker (published to GHCR), Nginx as a reverse proxy, and Watchtower for continuous automated deployments.
*   **Students' Union Platforms (AAUE):** Developing and maintaining websites and digital platforms for the *Associação Académica da Universidade de Évora* (University of Évora Students' Union), ensuring reliable digital services for the student body.
